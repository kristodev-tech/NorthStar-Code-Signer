# Security reporting

Do not publish signing certificates, private keys, passwords or sensitive local paths in an issue. For a vulnerability, use the repository's private vulnerability reporting feature if enabled, or contact the maintainer through a verified private channel listed on their GitHub profile. Never include a real PFX in a public reproduction.

Include the app version, Windows version, steps using disposable files, expected behavior and a redacted report. This tool provides signing and signature inspection, not antivirus scanning or a guarantee of public trust.
